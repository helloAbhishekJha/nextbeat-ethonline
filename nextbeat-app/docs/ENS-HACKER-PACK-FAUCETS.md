## Faucets — claim checklist

Pack perks tagged **Faucet** / **Credits** typically need:

1. **Mint Hacker Pack** (or hold pack NFT in verified wallet).  
2. Open **ETHGlobal dashboard** → **Packs** → **Perks** → each **Claim** before expiry.  
3. Use **same wallet** you use for dev (or a dedicated hot wallet — **no mainnet seed in chat**).  
4. For **testnet ETH**: official Sepolia/Holesky faucets if pack points to them; save addresses in `.env.example` only locally.
